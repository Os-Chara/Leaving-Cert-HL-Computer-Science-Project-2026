Overview of Project:


This project presents a tree-mounted forest wildfire monitoring system built around a Raspberry Pi Pico W.

The embedded system continuously collects temperature, humidity, and soil moisture data, processes this data through a local wildfire risk model, and triggers a physical alert when thresholds are exceeded.

Collected data is stored as a CSV file and transmitted wirelessly via HTTP to a computer, where a Python model processes the data into probabilistic risk scores, runs two what-if scenarios, and visualises data across comparative subplots.

The system was designed with real-world application in mind, and is tailored to Ireland's climate and its increasingly serious wildfire problem.
